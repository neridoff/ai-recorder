# AI Recorder

[![CI](https://github.com/neridoff/ai-recorder/actions/workflows/ci.yml/badge.svg)](https://github.com/neridoff/ai-recorder/actions/workflows/ci.yml)

Приложение для Mac, которое записывает онлайн-встречи и само делает из записи текст с разметкой, кто говорит.

- Живёт в строке меню: одна кнопка «Начать запись».
- Пишет звук собеседников (системный звук) и ваш микрофон отдельными дорожками.
- После остановки расшифровывает разговор и размечает говорящих: «Я», «Собеседник 1», «Собеседник 2»…
- Всё работает **на вашем Mac, без интернета**. Звук и текст никуда не отправляются.

Результат — файл `transcript.md`, который можно читать, править и отдавать в любой сервис для саммари.

## Перед первой записью

> **Предупредите участников встречи и получите их согласие на запись.** Запись разговора без согласия может нарушать закон и правила вашей компании.

Приложение не отправляет текст во внешние сервисы. Если хотите получить саммари, вы сами копируете текст из `transcript.md`, например в чат-бот. Перед этим проверьте, можно ли передавать этот текст по правилам вашей компании.

## Установка

**Что нужно:**
- Mac на Apple Silicon (M1 или новее);
- macOS 13.3 или новее;
- около 2 ГБ свободного места;
- интернет на время установки.

Полный Xcode не нужен: если инструментов разработчика нет, установщик предложит их поставить.

**Откройте Терминал и выполните две команды:**

```bash
git clone https://github.com/neridoff/ai-recorder.git "$HOME/Library/Application Support/AI Recorder/source"
```

```bash
cd "$HOME/Library/Application Support/AI Recorder/source" && ./install.sh
```

Установщик скачает модели распознавания речи (около 610 МБ), соберёт приложение прямо на вашем Mac и положит его в «Программы». Поэтому macOS не ругается на «неизвестного разработчика». Обычно это занимает 5–15 минут, в основном уходит на загрузку.

**Что будет на экране:**

```
[1/5] Инструменты разработчика ................... есть
[2/5] Библиотека sherpa-onnx (около 9 МБ) ........ готово
[3/5] Модели (около 610 МБ) ...................... готово
[4/5] Сборка приложения .......................... готово
[5/5] Установка в /Applications .................. готово

Установка завершена: /Applications/AIRecorder.app
```

В конце придёт уведомление «AI Recorder установлен». Оно будет от имени Терминала, а не со значком приложения: так macOS показывает уведомления скриптов.

**Что сделать руками:**
1. Если появилось окно установки инструментов разработчика — подтвердите, дождитесь конца и снова запустите `./install.sh`.
2. Установщик откроет Системные настройки на разделе «Запись экрана и системного звука». Включите там **AI Recorder** и перезапустите приложение: значок в строке меню → «Выйти», затем откройте AI Recorder из «Программ».
3. При первой записи macOS спросит разрешение на микрофон — нажмите «Разрешить».

Если у вашей учётной записи нет прав на папку `/Applications`, приложение ставится в `~/Applications` (папка «Программы» в вашей домашней папке). Если что-то пошло не так, установщик покажет номер шага и последние строки журнала. Полный журнал лежит в `~/Library/Logs/AI Recorder/install.log`.

## Как пользоваться

В строке меню появится значок волны. В меню:

- **Начать запись / Остановить запись** (⌘R). Во время записи есть **Пауза** (⌘P).
- **Несколько голосов в комнате** — включите, если рядом с вами говорят другие люди: тогда ваш микрофон тоже размечается по говорящим.
- **Не удалять аудио этой записи** — аудио этой встречи не будет удалено по сроку хранения.
- **Записи без результата** — записи, которые не удалось обработать. Их можно повторить, открыть в Finder или удалить в Корзину.
- **Показать последнюю запись в Finder**, **Открыть папку записей**, **Настройки…** (⌘,), **Проверить обновления…**, **Выйти**.

После «Остановить запись» обработка начинается сама. В меню видно «Расшифровка, N%», затем «Разметка, N%». Когда всё готово, приходит уведомление: клик по нему открывает расшифровку. Час записи обрабатывается примерно за 6 минут. Пока обрабатывается одна запись, можно начинать следующую.

Значок в строке меню показывает состояние:

| Значок | Что значит |
|---|---|
| волна | ожидание |
| волна с красной точкой | идёт запись |
| круг с паузой | пауза |
| мигающие полоски | идёт расшифровка или разметка |
| круг с «!» | обработка не удалась, запись в списке «Записи без результата» |

## Где лежат записи

Каждая встреча — отдельная папка в `~/Documents/AI Recorder`, например `Встреча 03.11.2026 10-32`.

| Файл | Что это |
|---|---|
| `transcript.md` | расшифровка для чтения: реплики с временем и говорящим, блок «Оценка» в начале |
| `transcript.json` | та же расшифровка в машинном формате |
| `mixed.m4a` | общая запись встречи (обе дорожки вместе) |
| `system.m4a`, `mic.m4a` | собеседники и ваш микрофон отдельно |
| `session.json` | служебные сведения о записи |

Во время записи звук пишется без сжатия, около 1 ГБ за полчаса. После обработки приложение сжимает его: час встречи занимает около 45 МБ.

`transcript.md` перезаписывается при повторной обработке. Свои правки сохраняйте в отдельный файл, например `reviewed.md` в той же папке.

## Настройки и хранение аудио

Окно **Настройки…** (⌘,), изменения применяются сразу:

- **Хранение.** Сколько хранить сжатое аудио обработанных записей и исходное аудио записей без результата: 1, 3, 7, 14, 30, 90 дней или «Не удалять». По умолчанию 7 дней. Удаляется только звук: текст и папка записи остаются. За сутки до удаления аудио необработанной записи приходит уведомление.
- **Обработка.** Запускать ли обработку сразу после «Стоп». Язык расшифровки: русский или определять автоматически.
- **Уведомления.** Уведомление о готовой расшифровке. Уведомления об ошибке и скором удалении приходят всегда.
- **Папка архива.** Где хранить записи (по умолчанию `~/Documents/AI Recorder`). Применяется после перезапуска приложения.

Аудио никогда не удаляется у записи, которая идёт или обрабатывается, и у записей с отметкой «Не удалять аудио».

## Обновление

В меню есть пункт **Проверить обновления…**. Если вышла новая версия, откроется окно с кнопкой **Скопировать команду**: вставьте её в Терминал и нажмите Enter. Пока вы не обновились, в меню виден пункт «Доступно обновление X.Y.Z».

Обновиться можно и сразу из Терминала:

```bash
cd "$HOME/Library/Application Support/AI Recorder/source" && git pull && ./install.sh
```

Установщик закроет старую версию, соберёт новую и заменит её. Если в этот момент идёт запись, он остановится и попросит её завершить.

> **После обновления macOS снова спросит разрешения.** Приложение подписывается заново при каждой сборке, и macOS считает новую сборку другим приложением. Включите запись экрана в открывшихся настройках ещё раз.

Если ничего не изменилось, повторный запуск `./install.sh` ничего не скачивает и не пересобирает.

## Если что-то не работает

**Запись не стартует, в меню «Нет разрешения „Запись экрана и системного звука“», хотя переключатель в настройках включён.** Так бывает после обновления: переключатель относится к старой сборке. Сбросьте разрешение и выдайте его заново:

```bash
osascript -e 'tell application id "com.neridov.airecorder" to quit'
tccutil reset ScreenCapture com.neridov.airecorder
open -a AIRecorder
```

Затем «Начать запись», разрешите в запросе macOS, выйдите из приложения и откройте его снова. С микрофоном так же: `tccutil reset Microphone com.neridov.airecorder`.

**В уведомлениях пустая плашка вместо значка.** Значок в уведомлениях собирается инструментом из полного Xcode. Без Xcode установщик предупредит об этом, на работу приложения это не влияет.

**Не приходят уведомления.** Системные настройки → Уведомления → AI Recorder: разрешите уведомления.

**Расшифровка не удалась.** Запись остаётся в меню «Записи без результата» с причиной. Нажмите «Повторить расшифровку»: обработка продолжится с того места, где остановилась.

**Журнал приложения** для разбора проблем:

```bash
log stream --predicate 'subsystem == "com.neridov.airecorder"' --info
```

## Удаление

1. Выйдите из приложения (значок → «Выйти») и перенесите **AI Recorder** из `/Applications` (или `~/Applications`) в Корзину.
2. При желании удалите `~/Library/Application Support/AI Recorder` (исходники и модели, около 1 ГБ) и `~/Library/Logs/AI Recorder`.
3. Записи в `~/Documents/AI Recorder` автоматически не удаляются: решите сами, нужны ли они.
4. Разрешения можно убрать в Системных настройках → Конфиденциальность и безопасность.

## Конфиденциальность

- Запись, расшифровка, разметка говорящих, сжатие и удаление аудио идут только на вашем Mac, без сети.
- Приложение выходит в интернет в одном случае: когда вы сами нажимаете «Проверить обновления…». Тогда уходит один запрос к GitHub (`api.github.com`). В нём нет ваших данных, только версия приложения. GitHub при этом видит IP-адрес вашего Mac. Во время записи и обработки этот пункт неактивен.
- Приложение ничего не скачивает и не устанавливает само. Команду обновления оно только копирует в буфер обмена.

| whisper.cpp | расшифровка | [ggml-org/whisper.cpp](https://github.com/ggml-org/whisper.cpp) | MIT |
| Whisper large-v3-turbo | модель расшифровки | [ggerganov/whisper.cpp](https://huggingface.co/ggerganov/whisper.cpp), исходная [openai/whisper-large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo) | MIT |
| Silero VAD | поиск речи в записи | [ggml-org/whisper-vad](https://huggingface.co/ggml-org/whisper-vad), исходная [snakers4/silero-vad](https://github.com/snakers4/silero-vad) | MIT |
| sherpa-onnx | разметка говорящих | [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) | Apache-2.0 |
| ONNX Runtime | запуск моделей разметки | [microsoft/onnxruntime](https://github.com/microsoft/onnxruntime) | MIT |
| pyannote segmentation-3.0 | где кто говорит | [csukuangfj/sherpa-onnx-pyannote-segmentation-3-0](https://huggingface.co/csukuangfj/sherpa-onnx-pyannote-segmentation-3-0), исходная [pyannote/segmentation-3.0](https://huggingface.co/pyannote/segmentation-3.0) | MIT (у исходной модели) |

## Для разработчиков

Сборка и тесты (Swift 5.9+, macOS 13.3+, Apple Silicon):

```bash
./scripts/fetch-sherpa-onnx.sh   # библиотеки sherpa-onnx в Vendor/ (один раз)
./scripts/fetch-models.sh        # модели в ~/Library/Application Support/AI Recorder/Models (один раз)
swift build && swift test
./scripts/build-app.sh           # build/AIRecorder.app и утилиты командной строки
open build/AIRecorder.app
```

Тесты не требуют моделей: движки расшифровки и разметки в них подменяются заглушками. Приложение подписывается без сертификата разработчика (ad-hoc), поэтому после каждой пересборки macOS может снова спросить разрешения (см. «Если что-то не работает»).

**Утилиты командной строки** (появляются в `build/` после `build-app.sh`, принимают папку записи; без аргумента берут последнюю):
- `verify-session` — проверить файлы записи;
- `mix-session` — свести дорожки в `mixed.m4a`;
- `transcribe-session` — расшифровать и разметить говорящих (`--all` — все необработанные);
- `diarize-session` — только разметка говорящих.

**Устройство:**

```
Sources/RecorderCore/     запись, сведение, расшифровка, разметка, хранение, проверка обновлений (без интерфейса)
Sources/WhisperEngine/    расшифровка на whisper.cpp
Sources/SherpaEngine/     разметка говорящих на sherpa-onnx
Sources/AIRecorder/       приложение в строке меню, настройки, уведомления
Sources/*-session/        утилиты командной строки
Tests/                    тесты
scripts/                  загрузка библиотек и моделей, сборка .app
install.sh                установка для пользователей
```

**CI и выпуск версии.** GitHub Actions на каждый push и pull request (кроме правок только в `.md`) собирает проект, гоняет тесты и собирает `.app` (`.github/workflows/ci.yml`). Чтобы выпустить версию:
1. Поднимите `CFBundleShortVersionString` и `CFBundleVersion` в `Resources/Info.plist`, запушьте в `main`, дождитесь зелёного CI.
2. Поставьте тег:
   ```bash
   git tag v0.2.0 && git push origin v0.2.0
   ```
3. Workflow `Release` проверит, что тег совпадает с версией в `Info.plist`, прогонит CI и создаст релиз. У пользователей «Проверить обновления…» покажет новую версию.

Готовое приложение к релизу не прикладывается: каждый собирает его у себя через `install.sh`.
